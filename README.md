## What I do

I build automations that replace repetitive ops work: ticket triage, account provisioning, monitoring rollups, document processing, and the long tail of "someone runs this script every Monday." The goal is fewer human handoffs, clearer audit trails, and systems that fail loudly instead of silently.

I come at automation from a 14-year IT and security background, so the work tends to be opinionated about logging, secrets handling, and least privilege rather than just "make the API call."
